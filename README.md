# 📈 Stock Price Direction Classifier

A Machine Learning project to predict next-day stock price movement (UP or DOWN) using technical indicators and Random Forest Classifier.

## 🔍 Problem Statement
Can we predict whether a stock's price will go UP or DOWN the next day using historical price data and technical indicators?

## ⚙️ Features Used
- RSI (Relative Strength Index)
- MACD & MACD Signal Line
- Bollinger Bands (Upper & Lower)
- 7-day & 21-day Moving Averages
- Daily Return & Volume Change

## 🏆 Results
| Metric | Value |
|--------|-------|
| Model | Random Forest Classifier |
| Stock | Apple (AAPL) 2018–2024 |
| Test Accuracy | ~55–60% |
